此刻的星澜

静静陪伴

01 / 09

轻微呼吸与发梢摆动，留一点安静给思考。

桌面版还支持拖动、缩放和置顶。自动姿态可在右键菜单中单独开启。

01 — PRESENCE

灵动，有分寸。

招手、跳跃、等待、检查。用姿态回应你，也可以随时暂停，安静留在桌面一角。

02 — LOCAL FIRST

陪伴，留在本地。

桌面角色无需账号或 API Key。不读取聊天内容，不记录键盘输入，没有云端对话或遥测。

03 — OPEN TO YOU

把灵感，继续写下去。

代码和角色素材一起开放。换一套动作、改一种交互，或者让她走进你的项目。

TAKE HER HOME

三步，让星澜来到桌面。

Windows 桌面版无需安装 Python。
其他系统可以先体验浏览器中的离线演示。

前往下载 ↗
  1. 01

    下载 Windows 压缩包

    在 Releases 页面选择 Windows x64 版 ZIP。

  2. 02

    完整解压，打开 Xinglan.exe

    保留文件夹中的配套文件，不要只取出 EXE。

  3. 03

    拖到喜欢的位置

    单击招手、双击跳跃；右键调整大小、状态或退出。

星澜是独立的开源桌面角色项目，使用 AI 辅助创作的角色素材。她不内置聊天模型，也不是 ChatGPT、Codex 或 DeepSeek 的官方客户端插件。桌面版的可选自动姿态只根据前台应用进程名切换场景，不代表识别到了 AI 的真实工作状态。
