# 星澜使用说明

## Windows 免安装版

1. 从 [Releases](https://github.com/luoshaobo69-arch/xinglan-desktop/releases/latest) 下载 Windows x64 ZIP。
2. 右键压缩包，完整解压到你喜欢的目录。
3. 双击 `Xinglan.exe`。无需安装 Python、注册账号或填写 API Key。
4. 单击角色招手，双击跳跃；拖动改变位置，右键打开菜单。

请保留整个解压文件夹。`Xinglan.exe` 旁边的配套文件是运行时和角色资源的一部分。

## 调整和互动

右键菜单提供手动状态、缩放、置顶、暂停、视线跟随、自动模式和退出。过大的缩放会显露原始 sprite 的分辨率；较小尺寸适合放在工作区角落。

暂停适合阅读或集中工作。关闭置顶后，其他窗口可以覆盖角色。退出后不会留下后台联网服务，也不会自动添加开机启动项。

本地配置只保存位置、缩放、显示与交互选项等偏好，不包含聊天内容。Windows 配置目录为 `%LOCALAPPDATA%\Xinglan`。遇到错误时，请按程序提示检查该目录下的日志。

## 可选的自动姿态

此功能默认关闭，需在右键菜单中开启。Windows 版按前台应用**进程名称**选择姿态：

| 前台应用场景 | 姿态 |
| --- | --- |
| VS Code / PyCharm / GPT | 工作 |
| Codex | 检查 |
| DeepSeek | 等待 |

它不是与这些产品的工作状态 API 连接，不知道对话是否正在生成、是否遇到错误或是否完成。它不读取窗口标题、代码文件或聊天内容。不同版本的应用可能使用不同进程名；如果没有匹配，可以使用手动状态。

星澜是独立桌面程序，不是这些客户端的官方插件，也不会更改它们的安装文件或配置。

## 浏览器互动演示

可以直接访问[在线演示](https://luoshaobo69-arch.github.io/xinglan-desktop/)，也可以完全离线使用：

- 下载 Offline Demo ZIP，完整解压，打开 `index.html`；或
- 下载仓库源码，打开 `docs/index.html`。

保持 `index.html`、`app.js`、`style.css` 和 `media` 在原来的相对位置。页面没有 CDN、统计脚本或聊天接口；下载与源码链接只有在你点击时才会打开外部网站。

动作按钮支持键盘操作。系统设置减少动态时，页面默认停止动画；也可手动切换“减少动态”或“暂停动作”。视线跟随仅在休息姿态生效，避免打断所选动作。招手、跳跃和遇到问题的反应播放一次后回到休息。

浏览器演示只展示角色互动，不会读取前台桌面应用。

## 源码运行

推荐使用 Python 3.11+ 的独立虚拟环境：

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python desktop\main.py
```

桌面版使用 Tkinter 和 Pillow。Tkinter 通常包含在 Windows 官方 Python 发行版中。当前发布和原生透明桌面效果主要面向 Windows；其他系统建议先使用离线网页演示。

运行随程序提供的自检：

```powershell
.venv\Scripts\python desktop\main.py --self-test
```

程序的自动姿态功能可以保持关闭，不影响其余手动互动。

## 常见问题

**找不到角色？**

先检查主屏右下角。星澜的透明悬浮窗口不显示任务栏按钮；可在任务管理器中确认 `Xinglan.exe` 是否运行。重新启动时，程序会把位置限制到主屏可见范围。不要同时启动多个副本来排查。

**下载包有发布者签名吗？**

当前 Windows 包未进行代码签名，系统可能显示“发布者未知”。下载请使用本项目 Releases，必要时核对同一发布中的 `SHA256SUMS.txt`，也可以按上面的步骤从源码运行。

**为什么她没有跟随 AI 的真实状态变化？**

自动模式只是前台应用的场景映射，不具备读取其他客户端任务状态的接口。你可以用右键菜单手动选择工作、等待或检查。

**为什么放大后没有更多细节？**

每个角色帧是 192 × 208 像素。程序缩放这些已绘制画面，不会重新生成高分辨率人物。推荐以适合桌面角落的尺寸显示。

**如何卸载？**

先通过右键菜单退出，再删除解压的程序文件夹。如果还要清除个人偏好，可删除 `%LOCALAPPDATA%\Xinglan`。原始下载和你自己的其他文件不受影响。
