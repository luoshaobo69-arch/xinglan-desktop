# 星澜 v1.0.0 — 你的桌面，也有一片星海

星澜的第一个公开版本。蓝发、星冠、蓝银礼服，还有一点安静又灵动的陪伴。

这次带来了：

- **Windows 免安装桌面版**：完整解压后打开 `Xinglan.exe`，无需安装 Python。
- **9 种动作与 16 个视线方向**：单击招手、双击跳跃、拖动移动，也能切换工作、等待、检查等姿态。
- **可调的陪伴感**：缩放、置顶、暂停与视线跟随；可选按前台应用进程名切换姿态。
- **离线互动演示**：浏览器直接打开，先和她打个招呼。
- **源码与角色素材**：代码 MIT，角色素材 CC BY 4.0，欢迎继续创作。

## 使用前知道这些

星澜独立运行，不需要账号、API Key 或聊天模型。自动姿态默认关闭；开启后只按前台应用进程名称映射场景，不读取聊天内容，也不能识别 AI 的真实生成状态。

当前原生桌面发布面向 Windows x64；其他系统可使用浏览器演示。角色为 AI 辅助创作的预绘制 sprite 动画。项目不属于 ChatGPT、Codex 或 DeepSeek 官方产品。

如果喜欢她，欢迎把这个项目分享给朋友。问题与建议可以在仓库 Issues 中提出。

**Xinglan v1.0.0 — A little company from the cosmos.**

A portable Windows companion with nine animation states, sixteen gaze directions, click-to-wave, double-click-to-jump, dragging, scaling and pause. An offline browser demo and the source are included.

The optional foreground-app scene mapping is off by default. It does not read chat content or detect a model's actual task state. No account or API key is required. Code: MIT. AI-assisted character assets: CC BY 4.0.
